# TangoBody 결과 페이지 1차 버그 수정 설계

## 목적

결과 페이지에서 확인된 빌드·빈 상태·조회 실패·작업 실패·메시지 불일치·측정 이력 문제를 수정한다. 오류 메시지 목록 31개와 기타 메시지 목록 29개는 추가하거나 변경하지 않고, 기존 문구가 정확한 실패 조건에서 표시되도록 연결한다.

보행 프레임 그래프는 백엔드에서 프레임별 머리·무릎 각도 데이터를 제공하지 않으므로 이번 수정에서 실제 데이터 전환을 보류한다. 고정 샘플 그래프 문제는 백엔드 API 제공 후 별도 수정한다.

## 적용 범위

- `/result-page`와 하위 경로
- 결과 페이지에서 사용하는 사용자 정보·측정 결과·측정 이력·결과 전송·결과 인쇄 코드
- 결과 페이지 로그인 서비스
- 결과 페이지 빌드를 차단하는 측정 목록 타입 변환

관리자 페이지와 공유하는 파일은 `isMyPage` 조건 또는 결과 페이지에서만 사용하는 분기에서 수정한다. 관리자 동작은 유지한다. 모든 운영 코드 수정에는 `GS 인증:` 주석을, 테스트에는 `GS 인증 테스트:` 주석을 작성한다.

## 메시지 정책

### 오류 메시지

- 측정 목록·상세 조회 실패: `검사 결과를 불러올 수 없습니다. 잠시 후 다시 시도해주세요.`
- 카카오 전송 실패: `카카오톡 공유에 실패했습니다. 잠시 후 다시 시도해주세요.`
- 통합 리포트 실패: `리포트 페이지를 생성하는 중 오류가 발생했습니다.`
- 기본·비교 이미지 인쇄 실패: `이미지 주소 생성에 실패했습니다.`
- 팝업 차단: `팝업이 차단되었습니다. 브라우저 설정에서 팝업을 허용해주세요.`
- 로그인 네트워크 실패: `서버와 연결할 수 없습니다. 잠시 후 다시 시도해주세요.`
- 로그인 서버·처리 실패: `로그인을 처리할 수 없습니다. 잠시 후 다시 시도해주세요.`
- 사용자 정보 저장 실패: `사용자 정보를 저장할 수 없습니다. 잠시 후 다시 시도해주세요.`
- 생년월일 미입력·형식 오류: `YYYY-MM-DD 형식으로 입력해주세요.`

로그인 인증 거절은 HTTP 400·401·422·423에만 `휴대폰 번호 또는 PIN 번호가 올바르지 않습니다.`를 사용한다. HTTP 500 등 서버 장애를 인증 실패로 표시하지 않는다. 계정 잠금 여부와 서버 상세 메시지는 계속 노출하지 않는다.

### 기타 메시지

- 측정 기록 0건 또는 선택 회차 결과 0건: `조회 가능한 검사 결과가 없습니다.`
- 측정 이력 0건: `조회 가능한 측정 이력이 없습니다.`

오류 메시지 31개와 기타 메시지 29개의 개수 및 문구는 유지한다.

## 상태 처리

### 최근 측정

측정 목록이 실제로 로딩 중일 때만 스켈레톤을 표시한다. 조회 성공 후 목록이 비어 있으면 결과 없음 메시지를 표시한다. 측정 목록이나 상세 조회가 실패하면 검사 결과 조회 실패 메시지를 표시한다.

### 측정 이력

측정 이력 조회 실패 상태를 전달하여 빈 화면 대신 검사 결과 조회 실패 메시지를 표시한다. 조회 성공 후 목록이 비어 있으면 기존 결과 페이지 메시지 경계가 측정 이력 없음 메시지를 표시한다.

### 전송과 인쇄

카카오 암호화와 전송 요청을 하나의 `try/catch`에서 처리한다. 통합 인쇄 암호화와 URL 생성을 하나의 `try/catch`에서 처리한다. 기본·비교 이미지 업로드와 암호화 과정에서 예외가 발생해도 이미지 주소 생성 실패 메시지를 표시한다.

팝업은 빈 창을 먼저 확보하고 `opener`를 제거한 뒤 리포트 URL로 이동한다. 창 확보에 실패하면 팝업 차단 메시지를 표시한다. 관리자 페이지의 기존 `noopener,noreferrer` 호출은 유지한다.

## 측정 데이터와 이력

측정 목록 변환은 `has_basic`, `has_rom`, `has_bia`, `has_gait`, `has_moire`를 API 응답의 실제 값으로 보존한다. 측정 이력의 검사 종류에 결과 페이지에서 모아레 표시를 추가하고, 보행·모아레만 존재하는 회차를 선택해도 대응 검사 탭을 선택한다.

측정 이력 표는 실제 다섯 열과 일치하도록 `검사 종류`, `결과 비교` 헤더를 추가한다.

## 보행 프레임 그래프 보류

현재 `gait_sequence_result`에는 시퀀스 요약값만 있고 `GaitSeqResult`가 요구하는 프레임별 머리·무릎 각도 배열이 없다. 실제 프레임 데이터 API와 타입이 확정될 때까지 고정 샘플 그래프의 데이터 전환은 구현하지 않는다. 이 항목은 1차 수정 완료 보고서에 미해결 항목으로 남긴다.

프로덕션 빌드를 막는 미사용 `data` 오류는 전달된 값을 의도적으로 보류한다는 `GS 인증:` 주석과 명시적인 참조로 해소한다. 이는 고정 샘플 그래프의 정확성 문제를 해결한 것으로 간주하지 않는다.

## 테스트

각 버그는 구현 전에 실패 테스트를 작성하고 RED를 확인한다.

- 로그인 400·401·422·423와 HTTP 500·네트워크 오류 분류
- 측정 목록 로딩·빈 상태·오류 상태 판정
- 생년월일 결과 페이지 메시지
- 카카오·통합 인쇄·이미지 인쇄 실패 메시지
- 팝업 차단과 `opener` 제거
- 측정 플래그 보존, 모아레 라벨, 보행·모아레 기본 탭
- 측정 이력 표 헤더

마지막에 전체 Vitest, 결과 페이지 관련 ESLint, `npx tsc --noEmit`, `npm run build`, `git diff --check`를 실행한다.

## 완료 기준

- 오류 메시지 31개와 기타 메시지 29개가 늘어나거나 변경되지 않음
- 결과 없음과 조회 실패가 무한 로딩 또는 빈 화면으로 남지 않음
- 전송·인쇄의 모든 실패 경로가 등록된 메시지를 표시함
- HTTP 500이 인증 실패로 표시되지 않음
- 팝업 차단 안내와 새 창 `opener` 제거가 함께 동작함
- 측정 플래그와 측정 이력 표시가 실제 응답과 일치함
- 관리자 페이지 기존 분기가 유지됨
- 보행 프레임 그래프 보류 사유가 완료 보고서에 명시됨
- 모든 수정 코드에 GS 인증 목적 주석이 있음
- 보행 프레임 API 보류 항목을 제외한 테스트·정적 검사·빌드가 통과함
