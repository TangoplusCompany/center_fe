# 결과 페이지 비활성 검사 안내 설계

## 목적

결과가 없는 검사별 사유를 본문에 여러 줄로 나열하지 않고, 비활성 검사 버튼과 상호작용할 때 화면 하단의 고정 안내로 제공한다. 변경은 결과 페이지에만 적용하며 관리자 페이지 동작은 유지한다.

## 화면 동작

- 결과가 없는 검사 버튼은 현재의 비활성 색상을 유지하며, 상호작용해도 검사 화면으로 전환되지 않는다.
- 비활성 버튼에 마우스를 올리면 화면 하단 중앙에 해당 검사 사유를 표시한다.
- 마우스가 버튼을 벗어나면 마우스 오버로 표시한 안내를 제거한다.
- 비활성 버튼을 클릭하거나 모바일에서 터치하면 같은 안내를 2초 동안 표시한 뒤 자동으로 제거한다.
- 키보드 `Enter` 또는 `Space` 입력도 클릭과 동일하게 2초 동안 안내한다.
- 안내가 표시되어도 비활성 검사 화면으로 이동하지 않는다.
- 안내 영역은 다른 화면 요소보다 앞에 보이도록 고정 배치하고, 상태 메시지로 보조기술에 전달한다.

## 메시지 정책

- 기존 기타 메시지 목록의 검사별 비활성 사유 문구를 그대로 사용한다.
- 본문에 검사별 사유를 여러 줄로 생성하던 동작은 제거한다.
- 다섯 검사 결과가 모두 없는 경우에는 본문의 `조회 가능한 검사 결과가 없습니다.` 안내를 유지한다.
- 오류 메시지 31개와 기타 메시지 29개의 항목 수 및 문구는 변경하지 않는다.

## 구현 범위

- 결과 페이지의 검사 종류 버튼에만 고정 안내 상호작용을 연결한다.
- 결과 페이지 전용 고정 안내 컴포넌트를 추가한다.
- 기존 결과 페이지 메시지 보정 코드에서는 검사별 본문 문구 생성을 제거하되, 전체 결과 없음 안내와 결과전송·인쇄 차단은 유지한다.
- 관리자 페이지에서는 기존 네이티브 비활성 버튼 동작을 유지한다.
- 모든 변경 지점에는 `GS 인증:` 주석을 남긴다.

## 접근성

- 결과 페이지의 결과 없는 버튼은 `aria-disabled="true"`로 상태를 제공한다.
- 클릭, 터치, 키보드 입력을 모두 지원한다.
- 고정 안내 영역에는 `role="status"`와 `aria-live="polite"`를 적용한다.

## 검증

- 마우스 진입·이탈 시 안내 표시와 제거를 확인한다.
- 클릭·터치·키보드 입력 후 2초 자동 제거를 가짜 타이머 테스트로 확인한다.
- 비활성 버튼에서 검사 전환 콜백이 실행되지 않는지 확인한다.
- 전체 결과 없음 안내와 결과전송·인쇄 차단이 유지되는지 확인한다.
- 관리자 페이지 동작이 변경되지 않았는지 확인한다.
- 전체 Vitest, ESLint, TypeScript 검사와 Next.js 빌드를 실행한다.
